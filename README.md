# FocusLab

Платформа: Windows Desktop (.NET 8) Технологічний стек: WPF · Entity Framework Core · ADO.NET · SQLite

Опис обраної теми
FocusLab — це десктопний застосунок для Windows, що об'єднує в одному локальному середовищі три ключові аспекти персональної продуктивності: управління задачами, фокусування на роботі (за технікою Pomodoro) та швидкий доступ до робочих ресурсів (файлів, папок, посилань), пов'язаних із конкретними задачами.
Ідея застосунку виникла з практичної проблеми: сучасна людина, що навчається або працює за комп'ютером, змушена одночасно тримати відкритими кілька окремих інструментів — таск-менеджер (наприклад, Trello), таймер Pomodoro (окремий сайт чи додаток), нотатник, а також вручну шукати потрібні файли й посилання щоразу, коли повертається до перерваної задачі. Це створює додаткове когнітивне навантаження, розсіює увагу та витрачає час, який мав би йти безпосередньо на виконання роботи.
FocusLab вирішує цю проблему шляхом створення єдиної точки входу: користувач створює задачу, прикріплює до неї необхідні файли/папки/посилання, запускає для неї фокус-сесію — і всі ці дії відбуваються в одному вікні, без перемикання між браузером, файловим провідником та сторонніми сервісами.
Актуальність теми
Зростання популярності "digital minimalism" та автономних (offline-first) інструментів — користувачі дедалі частіше цінують застосунки, які не вимагають постійного інтернет-з'єднання, не збирають персональні дані на віддалених серверах і працюють швидко завдяки локальному зберіганню.
Поширення техніки Pomodoro та методик тайм-менеджменту серед студентів і фахівців, що працюють віддалено.
