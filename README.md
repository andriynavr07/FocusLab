# FocusLab 

**FocusLab** — це автономний (offline-first) десктопний застосунок для Windows, призначений для підвищення персональної продуктивності. Застосунок об'єднує в єдиному середовищі управління задачами, фокусування за технікою Pomodoro та швидкий запуск локальних і мережевих ресурсів, пов'язаних із конкретними завданнями.

---

##  Основні можливості

- **Модуль задач (Канбан-дошка):** Візуалізація робочого процесу, керування пріоритетами, дедлайнами, тегами, проєктами та чек-листами підзадач.
- **Модуль фокусу (Pomodoro):** Вбудований таймер із гнучким налаштуванням сесій і перерв, безпосередньо прив'язаний до карток задач та інтегрований із модулем аналітики.
- **Модуль швидкого запуску (Quick Launcher):** Прикріплення локальних файлів, папок та URL-посилань до задач із можливістю відкриття в один клік через системні асоціації ОС.
-  **Модуль нотаток та бази знань:** Швидка фіксація ідей, конспектів та документації в контексті проєктів або окремих задач.
- **Модуль аналітики та звітності:** Наочна статистика продуктивності, аналіз розподілу фокус-часу та експорт звітів у CSV.

---

##  Технологічний стек

- **Платформа:** Windows Desktop (.NET 8)
- **UI Framework:** WPF (Windows Presentation Foundation) з використанням патерну **MVVM**
- **База даних:** SQLite
- **Доступ до даних:** 
  - **Entity Framework Core** — Code-First підхід, міграції та CRUD-операції
  - **ADO.NET** — прямі високопродуктивні SQL-запити для модуля аналітики та масових операцій

## Чому саме FocusLab? 

Більшість сучасних інструментів розсіюють увагу користувача між різними застосунками та вимагають постійного підключення до мережі. **FocusLab** усуває цей бар'єр.

| Критерій | Notion | TickTick | Trello | FocusLab 🎯 |
| :--- | :---: | :---: | :---: | :---: |
| **Автономність (Offline-first)** | Обмежена | Часткова | Відсутня | **Є** |
| **Швидкий доступ до локальних файлів/папок** | Відсутній | Відсутній | Відсутній | **Пряма інтеграція з ОС ** |
| **Вбудований Pomodoro-таймер** | Відсутній | Наявний (Premium) | Лише через плагіни | **Нативний, прив'язаний до задач** |
| **Простота та швидкість роботи** | Низька (Electron) | Висока | Середня | **Нативна продуктивність WPF** |
