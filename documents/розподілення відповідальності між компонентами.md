# Розподіл відповідальності між компонентами FocusLab (Separation of Concerns)

Документ описує чітке розмежування ролей та відповідальностей між шарами WPF-застосунку FocusLab для забезпечення чистої архітектури, легкого тестування та високої продуктивності.

---

## 1. Презентаційний шар (View Layer — WPF / XAML)
**Основна мета:** Відображення UI, оформлення та взаємодія з користувачем.

* **Основні обов'язки:**
  * Описування розмітки користувацького інтерфейсу через XAML.
  * Стилізація, анімації, теми та візуальні ефекти.
  * Обробка подій Drag & Drop для Канбан-дошки на рівні візуальних контролів.
  * Глобальні гарячі клавіші (Hotkeys) та прив'язка команд (Command Bindings).
* **Принцип:** *Zero Code-Behind*. Жодної бізнес-логіки, валідації чи прямих звернень до баз даних у коді `MainWindow.xaml.cs`.

---

## 2. Шар логіки представлення (ViewModel Layer — MVVM)
**Основна мета:** Зв'язуюча ланка між UI та бізнес-сервісами (State Management & Orchestration).

* **Основні обов'язки:**
  * Збереження та оновлення стану екранів (`ObservableCollection`, властивості з реалізацією `INotifyPropertyChanged`).
  * Обробка команд користувача через `ICommand` / `RelayCommand` (наприклад: *Створити задачу*, *Запустити Pomodoro*, *Відкрити файл*).
  * Попередня валідація введених даних користувачем перед передачею в сервіси.
  * Трансформація доменних моделей у зручні для відображення UI-моделі (Value Converters).

---

## 3. Шар доменної бізнес-логіки (Domain Services)
**Основна мета:** Реалізація всіх бізнес-правил та системних дій застосунку.

* **`TaskService` (Сервіс управління задачами):**
  * Логіка зміни статусів задач, сортування, фільтрації та перевірки наближення/прострочення дедлайнів.
* **`QuickLauncherService` (Сервіс швидкого запуску):**
  * Валідація існування файлів та директорій на диску (`File.Exists`, `Directory.Exists`).
  * Безпечний виклик і запуск зовнішніх системних процесів, папок або URL-адрес у браузері за допомогою `Process.Start`.
* **`PomodoroService` (Сервіс фокус-сесій):**
  * Фоновий таймер зворотного відліку.
  * Керування інтервалами та фазами (робоча сесія / коротка перерва / довга перерва).
  * Виклики нативних сповіщень Windows (Toast Notifications) при завершенні таймера.

---

## 4. Шар доступу до даних (Data Access Layer — DAL)
**Основна мета:** Надійне та автономне збереження даних у локальній базі.

* **`EF Core (AppDbContext)` — Object-Relational Mapping:**
  * Обробка стандартних CRUD-операцій (створення, читання, оновлення, видалення) для задач, тегів та зв'язаних ресурсів (`US-1.1`, `US-2.1`).
  * Автоматичне застосування міграцій та створення локального файлу SQLite при першому старті (`US-5.1`).
* **`ADO.NET (Direct SQL Query Execution)` — High-Performance Analytics:**
  * Виконання прямих асинхронних SQL-запитів із агрегаціями (`GROUP BY`, `SUM`, `COUNT`) для модуля аналітики (`US-4.1`).
  * Забезпечення максимальної швидкості вибірки звітних даних без перевантаження ORM-шару.
* **`SQLite Database`:**
  * Автономне файлове сховище (`focuslab.db`), яке зберігається на локальному ПК користувача.

---

## Схема взаємодії шарів

```
[ View (XAML) ] 
       │ Data Binding & Commands
       ▼
[ ViewModel ] 
       │ Service Calls
       ▼
[ Domain Services (Task, QuickLaunch, Pomodoro) ]
       │ Data Operations
  ┌────┴────────────────────────┐
  ▼                             ▼
[ EF Core (CRUD) ]     [ ADO.NET (SQL Analytics) ]
  └────┬────────────────────────┘
       ▼
[ Local SQLite DB ]
